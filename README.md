# 🚀 SmartTask Organizer

Sistema completo de gestión de tareas con reconocimiento de voz, categorías, fechas límite y base de datos SQLite.

## ✨ Características

### ✅ Historias de Usuario Implementadas:
1. **HU01 - Crear Tarea**: Formulario completo con validación
2. **HU02 - Listar Tareas**: Vista con filtros por categoría
3. **HU03 - Editar Tarea**: Modificación de todos los campos
4. **HU04 - Eliminar Tarea**: Diálogo de confirmación paso a paso
5. **HU05 - Completar Tarea**: Marcar tareas como completadas
6. **HU06 - Fecha Límite**: Gestión y detección automática de vencimientos

### 🎤 Funcionalidades Adicionales:
- **Reconocimiento de voz**: Crear/listar tareas por voz
- **Síntesis de voz**: Respuestas auditivas del sistema
- **Base de datos SQLite**: Persistencia completa de datos
- **Interfaz gráfica moderna**: Con Tkinter y estilos personalizados
- **Estadísticas en tiempo real**: Seguimiento de progreso
